# NTP Time Client

**NTP Time Client** — консольна програма мовою Rust для отримання часу від NTP-серверів через UDP.

Курсовий проєкт із дисципліни «Системне програмування». Варіант №6 — NTP Time Synchronization.

## Можливості

- Надсилання NTPv4-запитів через UDP, порт 123.
- Отримання часу від NTP-сервера.
- Відображення часу UTC та місцевого часу.
- Обчислення мережевої затримки (delay).
- Оцінювання зміщення локального годинника (offset).
- Налаштування сервера, кількості запитів та інтервалу через CLI.
- Перевірка коректності NTP-відповідей.
- Обробка мережевих помилок і таймаутів.
- Запис результатів і помилок у `logs/ntp.log`.
- Автоматичне тестування.

## Вимоги

- Rust та Cargo (стабільна версія).
- Windows, Linux або macOS.
- Підключення до інтернету.
- Доступ до UDP-порту 123.

## Встановлення

Клонуйте репозиторій:

```bash
git clone https://github.com/Moskaliuk343/ntp_time_client.git
cd ntp_time_client
```

Зберіть проєкт:

```bash
cargo build --release
```

## Запуск

Стандартний запуск:

```bash
cargo run
```

Вибір сервера:

```bash
cargo run -- --server time.google.com
```

Три запити з інтервалом 16 секунд:

```bash
cargo run -- --server pool.ntp.org --count 3 --interval 16
```

Відображення довідки:

```bash
cargo run -- --help
```

## Параметри командного рядка

| Параметр | Опис | Значення за замовчуванням |
|---|---|---|
| `--server HOST` | Адреса NTP-сервера | `pool.ntp.org` |
| `--count N` | Кількість запитів, 1–100 | 1 |
| `--interval N` | Інтервал між запитами, 16–3600 секунд | 64 |
| `--help` | Довідка | — |

## Журналювання

Програма автоматично створює папку `logs` та файл `ntp.log`.

У журналі фіксуються початок роботи, успішні NTP-запити, помилки, затримка мережі, зміщення годинника та підсумкова статистика.

## Тестування

Запустіть автоматичні тести:

```bash
cargo test
```

Перевірте програму:

```bash
cargo check
```

## Структура проєкту

```text
src/
├── main.rs
├── config.rs
├── ntp.rs
├── ntp_packet.rs
└── logger.rs
```

- `main.rs` — головний алгоритм програми.
- `config.rs` — обробка параметрів запуску.
- `ntp.rs` — UDP-запити та обчислення часу.
- `ntp_packet.rs` — перевірка NTP-відповідей.
- `logger.rs` — запис результатів у журнал.

## Обмеження

Програма є навчальним NTP-клієнтом і не змінює системний годинник комп'ютера. Вона показує оцінку часу та зміщення на основі окремих NTP-вимірювань, а не реалізує повноцінний механізм дисциплінування системного годинника.

Для роботи потрібен доступний NTP-сервер. Використані NTP-відповіді не мають криптографічної автентифікації.
